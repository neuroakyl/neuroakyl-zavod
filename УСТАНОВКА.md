# Установка завода — инструкция для Claude Code

Человек — новичок. **Всё, что можешь, делай сам.** От него только клик в системном окне, вход в браузере и ключи. Не проси открывать Терминал.
Одно действие за раз: что он увидит и куда нажать. Говори на его языке.

Завод ставится **поверх пакета «Умный Claude»**: тот создаёт папку Projects (мозг, материалы, завод), файл ключей `~/.claude/.env`,
автономный режим и `PYTHONUTF8=1` для Windows. Нет пакета — сначала поставь его (README пакета), потом завод. Без пакета завод тоже
встанет, но Windows-настройки и проверка будут слабее.

Python: везде `sh "$HOME/.claude/umnyi/bin/py" <скрипт>` (находит рабочий Python и на Windows, и на Mac). Без пакета: Windows `py`, Mac `python3`.
Ниже `PY` — эта команда, `Z` — папка завода `~/.claude/skills/zavod`.

## 1. Что ставим
Спроси одной строкой: «Ставлю весь завод или нужна часть: монтаж, разбор конкурентов, креатив, Telegram-бот?». Не ответил — всё.
И вторую: «Интернет быстрый или с телефона?» — от этого флаг ниже.
- Всё: `PY Z/install.py`. Монтаж качает ~0,5 ГБ, 5–20 минут: скажи, что ждём.
- **Слабый интернет:** `PY Z/install.py --light --bez-paka` (Node, ffmpeg, Remotion, без пака звуков и библиотек-образцов).
  Оборвалось — запусти ту же команду ещё раз: докачает с места. Пак — потом, тем же `install.py` без `--bez-paka`, когда будет Wi-Fi.
- Часть: `PY Z/install.py --chasti montazh` (части: `montazh`, `parser`, `karuseli`, `bot`). Креативу без монтажа нечем собрать ролик —
  ставь их вместе. Конкурентам нужен `parser` (расшифровка). Аватар и выкладка не требуют установки, только подключение.
- `install.py` создаёт папку `Projects/завод` (local.md, планы, ролики, креатив, медиатека, конкуренты) и дописывает в `~/.claude/.env`
  пустые строки для ключей завода. Код завода и монтажа живёт в `~/.claude/skills/`, данные человека туда не кладутся.

Есть `✗` — прочитай строку и почини сам. После монтажа выполни его `УСТАНОВКА.md` (папка `montazh` рядом): шаги 2 и 3.

## 2. Настройки (`Projects/завод/local.md`)
По одному вопросу, ответы пиши в `local.md`: ник, язык роликов, площадки, призыв в конце. Можно «потом». Не переспрашивай записанное.
Ниша, продукт, аудитория — не сюда, а в мозг (`модули/мозг.md`, интервью в уроке 3).

## 3. Ключи — только нужные выбранным частям, по одному, когда понадобятся
Открой файл ключей сам: Mac `open -e ~/.claude/.env`, Windows `notepad "$USERPROFILE\.claude\.env"`. Скажи: «вставь ключ после знака =
в строке <ИМЯ>, сохрани и закрой». Ключи в чат не проси, сам файл не читай — `proverka.py` скажет, вставлен ли ключ.
- **Конкуренты:** console.apify.com → Settings → API & Integrations → `APIFY_TOKEN` (бесплатно $5 в месяц, карта не нужна).
- **Расшифровка, кыргызский:** aistudio.google.com/apikey → `GEMINI_API_KEY` (бесплатно).
- **Голос без лица:** elevenlabs.io/app/settings/api-keys → `ELEVENLABS_API_KEY` (на бесплатном тарифе — не для рекламы и клиентов).
- **Креатив:** kie.ai → API Key → `KIE_API_KEY`, пополнить баланс. Оплата картой зависит от страны — не прошла, скажи, что случилось.
- **Выкладка:** buffer.com, подключить площадки; publish.buffer.com/settings/api → Personal Access → New Key → `BUFFER_API_KEY`.
- **Telegram-бот:** `TELEGRAM_BOT_TOKEN` — модуль `бот.md`.
- **Аватар:** claude.ai → Настройки → Connectors → HeyGen → Connect. Ключ не нужен.

## 4. Проверка
`PY Z/proverka.py --render --ostavit` — программы, папки, ключи (только есть / нет) и черновой ролик на заглушках (1–3 минуты, бесплатно).
Все `✓` и в конце «ЗАВОД РАБОТАЕТ». Покажи человеку черновой ролик (открой файл). `!` — что ещё не подключено, скажи одной строкой.
По частям, если ставили:
- Креатив: `kreativ.py new Projects/завод/креатив/проба --format vertical`, 2 кадра, `kadry --fake`, `klipy --fake`, `sobrat` в движок ролика
  (`ролик/rolik.py new`), `rolik.py render`. Покажи файл.
- Конкуренты: `konkurenty.py poisk "ниша" --fake`, `sbor proba_00 --fake`, `reiting` — видно, как будет выглядеть разбор.
- Выкладка: `vykladka.py kanaly` показывает его площадки.
- Аватар: `get_current_user` отвечает.
- Бот: `бот/bot.py proverka`.

Чего не удалось проверить — скажи прямо, не говори «всё готово».

## 5. Первый настоящий ролик
Порядок обучения: мозг (интервью) → конкуренты → контент-план «широко → узко» → первый ролик в формате, на который есть сервисы
(без денег — без лица с голосом человека или живая съёмка). Завод настроен, когда человек посмотрел свой ролик.

## Обновление
`git -C Z pull`, потом снова `PY Z/install.py` (доставит новое, данные в Projects не трогает).
