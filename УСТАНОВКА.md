# Установка завода — инструкция для Claude Code

Человек — новичок. **Всё, что можешь, делай сам.** От него только клик в системном окне, вход в браузере и ключи. Не проси открывать Терминал. Одно действие за раз: что он увидит и куда нажать.

## 1. Что ставим
Спроси одной строкой: «Ставлю весь завод или нужна часть: монтаж, креативные ролики, аватар, выкладка?». Не ответил — ставь всё.
- Всё: `python3 install.py` (Windows: `py install.py`). Монтаж качает ~0,5 ГБ и пакеты, 5–20 минут: скажи, что ждём.
- Часть: `python3 install.py --chasti montazh` (части: `montazh`, `parser`, `karuseli`). Креативу без монтажа нечем собрать ролик, ставь их вместе. Аватар и выкладка не требуют установки, только подключение.

Есть `✗` — прочитай строку и почини сам. После монтажа выполни его `УСТАНОВКА.md` (папка `montazh` рядом): шаг 2 и 3.

## 2. Настройки (`local.md`)
По одному вопросу, ответы пиши в `local.md`: ник, ниша и что продаёт, кому, язык роликов, призыв в конце, папка для роликов (предложи `Документы/Завод`, создай сам). Можно «потом». Не переспрашивай то, что уже записано.

## 3. Ключи — только нужные выбранным частям
Открой файл сам: Mac `open -e .env`, Windows `notepad .env`. Скажи: «вставь ключ после знака =, сохрани и закрой». Ключи в чат не проси.
- **Креатив:** kie.ai → войти → API Key, пополнить баланс. Предупреди: минимальная сумма и оплата картой зависят от страны, если не проходит — скажи, что случилось.
- **Выкладка:** buffer.com, подключить площадки; publish.buffer.com/settings/api → Personal Access → New Key.
- **Сбор рилсов:** console.apify.com → Settings → API.
- **Разбор видео, кыргызский:** aistudio.google.com/apikey.
- **Аватар:** claude.ai → Настройки → Connectors → HeyGen → Connect. Ключ не нужен.

## 4. Проверка
Завод считается установленным только после проверки того, что поставлено. Бесплатно:
- Монтаж: кадр из шаблона, покажи человеку (его `УСТАНОВКА.md`).
- Креатив: `kreativ.py new проба --format vertical`, заполни 2 кадра, `kadry --fake`, `klipy --fake`, собери и отрендери 3 секунды `COMP=Klipy`. Покажи файл.
- Выкладка: `vykladka.py kanaly` показывает его площадки.
- Аватар: `get_current_user` отвечает.

Чего не удалось проверить — скажи прямо, не говори «всё готово».

## 5. Первый настоящий ролик
Предложи собрать цифровой мозг (`модули/мозг.md`) и сделать первый ролик. Завод настроен, когда человек посмотрел свой ролик.
