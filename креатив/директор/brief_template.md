# Креативный бриф (универсальный)

```
ПРОЕКТ: …
ФОРМАТ / ПЛОЩАДКА: … (напр. Reels 9:16, 30 сек)

1. ЦЕЛЬ (одна): …            # что зритель сделает
2. АУДИТОРИЯ: …             # кто + боль/желание
3. ИНСАЙТ: …                # правда о зрителе, на которой держится идея
4. ГЛАВНОЕ СООБЩЕНИЕ (одно): …
5. ОФФЕР / CTA: …
6. BIG IDEA (крючок): …     # как подадим сообщение необычно
7. ТОН И СТИЛЬ: …
8. ОБЯЗАТЕЛЬНО показать: …
9. НЕЛЬЗЯ: …                # бренд-стоп, анахронизмы, табу
10. РЕФЕРЕНСЫ: …
11. МЕТРИКА УСПЕХА: …

ПАЙПЛАЙН (заполняется автоматически):
- Форматный плейбук: …
- Раскадровка: vertical-storyboard (если видео 9:16)
- Промпты визуала: photoreal-prompt
- Выбор моделей: ai-model-router
- Копирайт/скрипт: prompt_frameworks.md (текст)
```

Принцип: одна цель, одна аудитория, одно сообщение, одна big idea. Если их больше — режь.
