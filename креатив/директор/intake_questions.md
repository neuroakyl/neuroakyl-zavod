# Вопросы для съёма брифа (спрашивать до генерации)

Задавай только недостающее, ≤3–4 за раз. Если ответа нет — предложи разумный дефолт и продолжай.

## Универсальные (любой формат)
1. **Цель:** что должно произойти после просмотра? (продажа / заявка / подписка / охват / имидж / обучение)
2. **Аудитория:** кто зритель? боль/желание/возражение?
3. **Формат и площадка:** reels/shorts, YouTube, лендинг, карусель, TV/preroll, сторис? 9:16 / 1:1 / 16:9?
4. **Хронометраж/объём:** сколько секунд / кадров / слайдов?
5. **Тон и стиль:** премиум / дерзкий / тёплый / документальный / игровой?
6. **Оффер/сообщение:** одно главное, что унести? есть ли акция/цена/дедлайн?
7. **Бренд-ограничения:** логотип, цвета, шрифты, tone of voice, что нельзя?
8. **Референсы:** есть ролики/картинки «как надо» / «как не надо»?
9. **Успех:** по чему поймём, что зашло? (CTR, заявки, досмотры, продажи)

## Доп. вопросы по типам
- **Реклама бизнеса:** УТП? цена/выгода? главное возражение? куда ведём (сайт/директ)? есть продукт-фото?
- **UGC/talking-head:** аватар или реальный человек? язык, акцент? скрипт есть?
- **Продуктовый ролик:** ключевые фичи в порядке важности? демо или эмоция?
- **Исторический/эпос:** канон-персонажи, сакральные ограничения, цитаты дословно.
- **Explainer:** какую мысль объясняем? уровень аудитории?
