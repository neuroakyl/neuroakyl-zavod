# Плейбуки форматов (каркас под каждый тип)

Каждый плейбук = структура + длина + соотношение + на что жать. Для видео 9:16 передавай раскадровку скиллу `vertical-storyboard`.

## 1. Реклама бизнеса / commercial (10–30 сек, 9:16 или 16:9)
Каркас: **Хук (боль/желание) → Проблема → Решение (продукт) → Выгода/доказательство → Оффер → CTA**.
Жать на: инсайт аудитории, одно возражение снять, оффер конкретный (цена/срок/бонус). Продукт-момент обязателен. CTA один.

## 2. UGC / talking-head (15–40 сек, 9:16)
Каркас: **Хук от первого лица → «я тоже так думал» → как продукт решил → доказательство/эмоция → мягкий CTA**.
Жать на: естественность, разговорный тон, «до/после». Аватар (Veo/HeyGen) + b-roll.

## 3. Reels / Shorts / TikTok (7–30 сек, 9:16)
Каркас: **Хук в 2 сек → быстрый ритм ценности/сюжета → петля/пуант → CTA/подписка**.
Жать на: скорость, субтитры, паттерн-брейк, нет скучных кадров.

## 4. Explainer / narrated (30–90 сек, 16:9 или 9:16)
Каркас: **Вопрос/проблема → аналогия → шаги/логика → вывод → применение**.
Жать на: ясность одной мысли, визуальные метафоры, темп под закадр.

## 5. Продуктовый ролик / demo (10–30 сек, 1:1 или 9:16)
Каркас: **Продукт-герой → фича 1 → фича 2 → сценарий использования → цена/CTA**.
Жать на: макро-детали, чистый свет, материал/текстура продукта.

## 6. Бренд-фильм / имидж (30–120 сек, 16:9)
Каркас: **Атмосфера → ценность/миссия → человеческий момент → лого-финал**.
Жать на: эмоцию и киношность, минимум текста, сильный звук.

## 7. Карусель / статик-кампания (4:5, 5–10 слайдов)
Каркас: **Слайд-хук → 3–5 пунктов ценности → соц-док → CTA-слайд**.
Жать на: первый слайд-крючок, единый визуальный стиль, читаемость с телефона.

## 8. Лендинг / промо-страница
Каркас: **Оффер-заголовок → подзаголовок-выгода → доказательства → как работает → отзывы → CTA (×N)**.
Жать на: один оффер, скан читаемость, повторяющийся CTA.

## 9. Исторический / эпос (9:16)
Каркас: **Эпик-хук → завязка → развитие (аттракционы) → пик-метафора → разрешение → CTA**.
Жать на: канон, реализм (анти-пластик), сакральность, дословные цитаты, LIGHT/LOCATION LOCK.

## Универсальное правило
Хук решает досмотр, оффер решает конверсию, консистентность решает доверие. Держи все три.
