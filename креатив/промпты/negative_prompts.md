# Готовые негатив-блоки (копируй нужный)

## Базовый анти-пластик (лицо/люди)
```
smooth skin, plastic skin, waxy, airbrushed, over-smoothed, blurry skin, doll,
cgi, 3d render, beauty filter, glossy, uncanny, mannequin
```

## Анатомия / артефакты
```
extra fingers, deformed hands, fused fingers, extra limbs, mutated, asymmetrical eyes,
distorted face, bad proportions, warped
```

## Экспозиция / оптика
```
overexposed, blown highlights, flat lighting, harsh flash, oversaturated, HDR look,
low detail, low resolution, jpeg artifacts
```

## Анахронизмы (для исторического/эпоса)
```
modern clothing, wristwatch, glasses, zipper, plastic, logos, text, watermark,
contemporary background, cars, electric lights
```

## Стилевой мусор (если лезет мультяшность)
```
cartoon, anime, illustration, painting, sketch, oversharpened, video-game render
```

## Скрытие лица (когда лицо героя нельзя показывать)
В промпт первого кадра добавь приём: `shown from behind` / `face turned away, out of frame` /
`backlit silhouette, face in deep shadow` / `framed from the chest down` / `face obscured by helmet shadow`.
В Negative добавь:
```
visible face, recognizable face, facing camera, front view of the face
```

## «Slop»-слова, которые НЕ пишем в позитив (дают пластик)
```
stunning, masterpiece, 8k, hyperdetailed, ultra realistic, award-winning, cinematic (само по себе)
```
Вместо них — конкретика: объектив, диафрагма, источник и направление света, плёнка, грейд.
