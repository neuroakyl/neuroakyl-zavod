# Чек-лист «нет скучных кадров» + связность

## Аттракцион (у каждого кадра ≥1)
- [ ] Необычный ракурс: аэро / низкий угол / через-плечо / dutch tilt
- [ ] Движение в кадре: пыль / ветер / знамёна / огонь / кони / толпа
- [ ] Сильный свет: контровой / лучи сквозь пыль / блик на металле
- [ ] Деталь-крупняк: глаза / лезвие / узор брони / руки
- [ ] Метафора / визуальный контраст (сталь vs мудрость и т.п.)
> Нет ни одного → переделать КАДР, а не промпт.

## Связность (весь ролик)
- [ ] Хук в первые 2–3 сек
- [ ] Крупность по синусоиде, нет двух одинаковых подряд
- [ ] Match-cut по свету и движению между кадрами
- [ ] LOCATION LOCK + LIGHT LOCK держатся
- [ ] Сквозная палитра/настроение
- [ ] Вертикаль работает глубиной (крупные/средние планы, движение из глубины)
- [ ] Одна эмоция и одна история от хука до CTA
