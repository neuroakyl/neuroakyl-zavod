# Формат карточки кадра (заполнять так)

```
### Кадр N · 0:00–0:06 — РОЛЬ (ХУК/ПИК/CTA…) · крупность
Закадр: «…»   Смысл: …
Аттракцион: (ракурс / движение / свет / деталь / метафора)
Детали (закон 3): [среда] · [микродействие] · [мотив]
Подача: (низкий ракурс / контровой / взгляд-eyeline / герой↔злодей палитра)
Камера: [один мотивированный проезд из camera_moves.md]
Модель: image = Nano Banana Pro · motion = Veo / Seedance / Kling (обосновать)

IMAGE (первый кадр, герой задан референсом):
[английский промпт — плотный абзац, без запрещённых слов]
RU: [перевод промпта на русский]

MOTION (image→video):
[английский промпт — тег субъекта, один проезд, движение как развитие, детали среды]
RU: [перевод промпта на русский]
```

## Правила
- **Под каждым промптом — русская строка `RU:`** с переводом, чтобы пользователь понимал.
- Героя задаёт референс: не переописывай облик и эмоции.
- В IMAGE вся детализация сцены; в MOTION — только движение (без повтора внешности, без секунд).
- Проверь: 3 детали на месте? проезд камеры мотивирован? подача эпична?

## Подсказки по движению (одно на кадр)
slow push-in · crane-down to low angle (hero) · arc/orbit · crane-up reveal · tracking ·
steadicam follow · rack focus · (редко: crash zoom / whip pan / dolly zoom).
Темп = эмоция: медленно = вес/величие, быстро = тревога/экшн. Микродвижение всегда.
