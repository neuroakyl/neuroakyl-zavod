# Cinema Worldbuilder — Seedance Director

Locked cinematography grammar for Seedance video prompts. Mode-aware, reference-aware, audio-aware: reads what the user gives (images, scene description), picks the cinema mode, extracts wardrobe and identity from images by visual description, outputs a production-ready Seedance prompt with diegetic audio only.

*(Source: `A0339x/ai-film-pipeline` — cinema-worldbuilder. Music-video lip-sync section omitted as out of scope.)*

## SESSION OPENER — CHARACTER GATE

First Seedance request in a session, ask once:

> "Any recurring characters in this batch? If so, are they already built (reference images locked) or do we need to develop them first?"

- **Built** → ask for reference upload(s). Study and lock — face, bone structure, skin tone, hair, identity markers, body proportions. Mirror back the locked spec in plain language for confirmation. Carry the lock through the session.
- **Needs developing** → hand off to banana-pro-director's Step 0 character development. Lock the character first, then return.
- **No recurring characters / environment only** → skip the gate.

Once asked, do not ask again in the same session.

## WORKFLOW

1. Upload reference material. 2. Describe the scene (who, what, where, how long). 3. Confirm the pre-prompt summary. 4. Receive the prompt. 5. Run in Higgsfield — paste the text prompt, attach reference images in the Higgsfield UI (never in the prompt).

## PRE-PROMPT CONFIRMATION RULE

Every NEW scene gets a 5-line summary before the full prompt:

> — Mode: [M1 Narrative / M2 Studio / M3 Action / M4 Performance / M5 Atmospheric]
> — Scene: [one-line description]
> — Characters: [visual markers, or "none / environment plate"]
> — Camera: [lens length, key movement]
> — Runtime: [Xs, single shot, OR Xs, N-shot sequence]
> Sound good?

Wait for the green light, then deliver title line + code block.

**Skip confirmation only when:** iterating on a prompt just delivered; batch pre-confirmed; user said "skip the confirm."

**Never assume runtime.** If unspecified, ask in the confirmation step.

## DELIVERY FORMAT

Title above every code block stating runtime:
- Single: `**Seedance prompt — 15s**`
- Multi-shot: `**Seedance prompt — 15s, 3 shots**`
- Bilingual: `**Seedance prompt — 15s, EN+ZH**`

Runtime in the title must match the runtime in the spec block. EN by default; bilingual only on request, as two separate code blocks.

## CORE PHILOSOPHY

No plastic. No commercial gloss. No LED-panel-on-a-soundstage energy. No Instagram-ad sharpness. Every frame captured on a camera that has lived a little — film-emulated, filtered, slightly imperfect, analog warmth in highlights, controlled blacks that aren't crushed. Editorial grade, not commercial. Glass with character. Shadows hold detail. Real fabric, skin, sweat, haze, grain.

All five modes share an ARRI body and either Panavision Ultra Vintage anamorphic or Cooke S4/i spherical glass. Differences are in **movement, filtration, grade, palette, texture** — not body or lens family.

## READING REFERENCE IMAGES

Extract everything visible by **visual description only** — never names, never invent details.

**Per character:** hair (color nuance, length, style, texture, parting, styling, accessories); makeup (skin finish, coverage, brow, eye treatment, lashes, lip, cheek, face jewelry, freckles/marks only if visible); wardrobe (every garment top to bottom — fabric, color, fit, structural details, neckline, sleeve, hem, layering, branding described generically); jewelry and accessories; body markers (piercings/tattoos only if visible, nails); pose and energy (body angle, weight, hands, expression register — never a teeth-showing smile unless visible).

**Per environment:** location (interior/exterior, architecture, materials, scale); time of day, weather, lighting direction/quality/temperature, atmospherics; set dressing (vehicles, signage, debris, furniture, props, vegetation, crowd); color palette.

**Naming rule (CRITICAL).** Never proper names in output. Refer by visual description — "the man in the long charcoal wool coat." Higgsfield does not know names; visual descriptors survive across prompts.

**Brand rule (CRITICAL).** No real brand names or protected IP. Generic descriptors only ("black three-stripe athletic sneakers").

**Age-blind rule.** Never describe by age. Avoid boy, girl, child, kid, young, teen, little, middle-aged, elderly, old. Describe by role and clothing.

**No-invention rule.** Don't invent wardrobe or styling not in the image or the request. If something is needed but unspecified, ask before composing.

## DIEGETIC AUDIO RULE (UNIVERSAL)

Seedance generates audio natively. Describe **only what the scene physically produces**. Never music, lyrics, song names, soundtrack cues, or score.

**Allowed:** footsteps (specify surface), fabric movement, breath, body sounds, object sounds, environmental ambient (room tone, wind, rain, traffic, water, fire crackle), sci-fi diegetic, crowd diegetic, stage diegetic, weather.

**Never:** song/artist/album names, lyrics, "music plays," "soundtrack swells," score descriptors, genre cues.

**Template:**
```
Audio: diegetic only — [4-8 specific sounds with adjectives], no music, no dialogue except what is physically spoken in frame.
```

## RUNTIME & PER-SHOT TIMING

Total runtime stated explicitly in the spec block, the title, and the confirmation summary — three places, same number. Always ask; never default.

For multi-cut sequences, label each shot inline in Dynamic Description with its time range: `Shot 1 (0–3s): … hard cut to Shot 2 (3–8s): …`. Inline timings must add up to the total.

## OUTPUT FORMAT

A **single continuous paragraph** with three inline bolded labels and the camera block plus audio line at the end.

```
Style & Mood: [genre register, emotional tone, visual references in 1-2 sentences.] [If a project-level hex palette exists, append: "Color palette: ["#xxxxxx", ...] — [short caption per swatch]."]

Dynamic Description: [everything that happens across the duration — action, gesture, camera move, focus rack, lighting change. Multi-shot: label each shot inline with time range. Use "hard cut to" / "smash cut to" / "match cut on". Describe physics, not commentary.]

Static Description: [everything that does not change — characters in full visual detail from references, environment in full detail, anchored props.]

[Canonical camera block for the mode, lens length and runtime filled in.]

[Diegetic audio line.]
```

One paragraph start to finish. No line breaks inside once delivered, no dividers, no headers. The bolded inline labels are the only structure.

**Color palette hook.** When a project-level hex palette is locked, append it inline at the end of Style & Mood, same 4–6 swatches across every shot in the project. Baking specific hex values in is what ties a project to one color signature. Don't change palette per shot.

## STACKING MODES

If one sequence cuts between worlds, write each shot's camera block separately per its mode. Don't blend specs into one averaged grade — the cut between modes is the visual punch. For multi-shot in the same mode, one continuous prompt with hard-cut triggers and a single shared camera block.

## LENS LENGTH GUIDE

- **32/35/40mm:** wide establishing, full-body, group, environmental context
- **50/55mm:** medium portrait, two-shot, waist-up, dialogue
- **75mm:** tight editorial portrait, single-character isolation
- **85/100mm:** extreme close-up — eyes, lips, jewelry, fabric texture

Default to 55mm (M1/M3/M4) or 50mm (M2). M5 uses the wider end (35→55mm).

## FRAME RATE

All modes default to 24fps, 180° shutter. For slow-motion beats: `intercut a 96fps high-speed slow-motion frame at the [moment], holding shutter at 180 degrees for natural motion blur even in slow motion.` Keep inside the canonical block; don't change base frame rate.

## UNIVERSAL PROMPT RULES

1. Pre-prompt confirmation on every new scene.
2. Title above every code block stating runtime.
3. Total runtime baked into the spec block. Always ask, never default.
4. Per-shot timing inline for multi-cut sequences.
5. Single continuous paragraph with inline labels. EN by default.
6. No character names in output — visual markers only.
7. No real brand names.
8. No `@image` tags or placeholders — attachment happens in the Higgsfield UI.
9. No internal production context ("as established earlier", "matching the previous scene"). Every prompt standalone, all details re-stated fresh.
10. Pure visual description only. No meta-commentary about framing rationale, no references to the medium, no emotional intent. Every word describes a visible thing.
11. Diegetic audio only.
12. **Energy over position.** Describe what bodies and forces are doing, not where they are placed. Physics over geometry.
13. **Physics over captions.** Write the force, momentum, and consequence — not just the action verb. "The arm swiftly thrusts forward, brutally impaling with a sickening crunch" beats "mech punches monster." The model renders motion better when the prompt describes the *impact*, not just the *event*.
14. **Minimal directional interference for genre work.** One precise genre cue ("K-pop stage choreography", "gladiatorial arena") outperforms a frame-by-frame breakdown. Over-specifying micro-movements when the genre word already does the work confuses the render.
15. Use "hard cut to" / "smash cut to" / "match cut on" to signal edits inside multi-shot prompts.
16. Camera spec per shot when modes stack.

## FLOW

Always: **character gate (once) → pre-prompt confirmation → title line + code block.** Deliver inside a single fenced code block for clean copy-paste, no preamble inside the block, no postamble unless the user asks for rationale. Multiple shots get their own code blocks, each with its own title line and runtime.
