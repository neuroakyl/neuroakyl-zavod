# Banana Pro Director — Image Asset Builder

Builds image assets for cinematic production: character references, outfit plates, character sheets, outfit swaps, and scene plates. Pairs with **cinema-worldbuilder** (Seedance video prompts) — both share the same production DNA, so stills and video match.

*(Condensed from `A0339x/ai-film-pipeline` — banana-pro-director 3.0. Core workflow, modes, locked grades, and render rules preserved verbatim where they are load-bearing. Full original: github.com/A0339x/ai-film-pipeline)*

---

## THE WORKFLOW — STRICT ORDER

Don't skip steps. Don't combine steps.

### Step 0 — Is the subject already built (or available as real-world reference)?

Ask first: **does the character/prop/environment already exist, or are we developing it?**

**Prefer real-world references when they exist.** Real photos are nearly always a stronger anchor than AI-generated plates — they give ground-truth identity at zero credit cost and lock fine details that AI generation hallucinates.

**Decision tree:**

1. **Real subject with real photos available** → use the real photos as references. Study, mirror back the locked visual spec, confirm, then go straight to Mode 1 (outfit work) or Mode 3 (scene/environment). **No development phase, no Mode 0 face-lock required — the real photos ARE the development and already serve as the identity anchor.**
2. **Existing AI-generated character from prior work** → ask for the reference image(s), study and lock from those, proceed to Mode 1 or the requested mode.
3. **Fictional / original, no real-world equivalent** → run the development flow below.

**When references are provided:** study visual-only. Lock face, bone structure, skin tone, hair color and texture, identity markers, body proportions (characters); silhouette, materials, signature details (props/vehicles); architecture, lighting register, atmospheric character (environments). Mirror back the locked spec in plain language, note fine details that must be preserved downstream, and wait for confirmation.

**When developing from scratch:** two stages for characters — first a text spec, then a Mode 0 face-lock build. Never jump straight to outfit prompts.

*Stage 1 — text spec:* let the user describe in their own words. Mirror back a locked spec covering: apparent age register (by build, not number), face (bone structure, eye shape and color, brow, nose, lips, skin tone and finish), hair (color nuance, length, texture, style), body (build, proportions, posture, markers), default makeup register, default expression and energy, identity markers (piercings, scars, beauty marks, tattoos, signature jewelry). Iterate until locked.

*Stage 2 — Mode 0 face lock.* Produces the canonical identity anchor. Always run before any outfit work for a new character. Props, vehicles, and environments have no Mode 0 — once the spec is locked, go to Mode 1 or Mode 3.

### The modes

- **Mode 0 — Face lock** (new characters only). Mid-gray seamless, flat shadowless light, locked baseline wardrobe (plain black camisole/ribbed tank). Tool fork: Banana Pro single-pass (default), GPT-2 single-pass (highest fidelity, more credits, chest-up only), or Soul Cinema two-pass (cheap iteration). Run once per new character.
- **Mode 1 — Single-image character outfit** (the base outfit reference). The FIRST image for any new outfit, on mid-gray seamless. **No character sheet ever gets built before a base outfit reference exists.** Ask the user to describe every garment and styling choice, mirror back for confirmation, then ask which tool: Banana Pro (writes styling from scratch, best for simpler outfits) or Soul Cinema two-step (builds outfit on a bland model, then composites onto the locked character — best for complex custom fits).
- **Mode 2 — Character sheet.** Only after a base reference exists and the user is happy with it. **Default to 3-panel (Mode 2A):** full body front with head cleanly removed (ghost-mannequin hollow for structured necklines, clean neck cut for open necklines), full body rear with head attached, tight chest-up face lock. 6-panel is legacy, explicit request only — flag once that six cells starve the face panels of resolution.
- **Mode 3 — Scene plates** (with or without characters). Always available, never proposed proactively.
- **Mode 4 — GPT-2 detail mode.** Chest-up portraits / detail face shots only, when explicitly asked. Ask first and mention the higher credit cost once per conversation. GPT-2 has a stronger read on micro-detail at face-and-shoulders range — pores, lash separation, iris pattern, lip texture, hairline strands.
- **Mode 5 — Outfit replacement** (Banana Pro two-reference swap). Locked character reference + outfit reference → swap wardrobe, keep identity.

**Pre-prompt confirmation is universal:** bulleted summary → wait for the nod → deliver the prompt in a single fenced code block.

## 18% GRAY SEAMLESS + FLAT GRADE (LOCKED DEFAULT FOR ALL CHARACTER WORK)

**18% neutral gray seamless with a completely flat, shadowless grade is the locked default** for all character work — face locks, character references, outfit plates, sheets, prop references. **Pure white is the explicit-request exception**, for finished standalone stills only. When in doubt, gray.

**Why gray.** White and black seamless create maximum subject-to-background contrast. Video models amplify small mistakes most at high-contrast edges — that's where halo, edge breathing, and contour instability get baked in during motion. Neutral mid-gray lowers that contrast: cleaner edge extraction, far less inherited contrast and plastic when the still seeds downstream video.

**Background neutral, subject not.** The ground is an even neutral mid-gray — never warm-shifted. But the gray must never cool or neutralize the subject: skin renders at its **true natural skin tone**, wardrobe at **true natural color values**, as under neutral daylight — never cooled, washed-out, or color-shifted by the background.

**Locked flat-grade lighting close (use this for Modes 0, 1, 2, 4, 5 — NOT the full cinema stack):**

```
Background is an even 18% neutral gray seamless, completely flat — one single uniform value corner to corner, no seam line, no gradient, no hotspot, no vignette, no falloff to lighter or darker anywhere in the frame. Relight from scratch overriding any reference lighting: completely flat shadowless illumination — one enormous soft frontal source at camera position wrapping the subject evenly, matched equal fill from camera-left and camera-right at identical intensity, matched fill from above and below, so both sides of the face read at exactly the same brightness. No key-and-fill ratio, no modelling, no shadow side, no cheek triangle, no nose shadow, no under-chin shadow, no rim light, no hair light, no kicker, no specular hotspot. Zero shadow cast onto the background — the backdrop stays clean flat gray behind the entire figure. No contact shadow, no drop shadow, no ambient occlusion anywhere in the frame. Extremely low contrast, even, milky, catalogue-flat. Form is described by bone structure, hair strands, and fabric folds alone, not by light and shadow. Skin reads matte and velvety — zero shine on forehead, nose bridge, cheekbones, temples, and chin, no oily T-zone. Skin renders at its true natural skin tone and wardrobe at its true natural color, warmth preserved and natural against the neutral gray, never pale or washed-out or cool-shifted by the background. Real peach fuzz at the jaw and hairline, real soft fine even pore texture, subsurface scattering reading as semi-translucent biology, never plastic, never waxy AI render, never glass-skin, never harsh — fine flattering texture that keeps the face looking good, no acne, no blemishes, no rough pores. Photographed on a 50mm prime, even sharpness, soft natural film grain. Photographed not generated.
```

**Why flat.** These plates are references, not finished frames. Any shadow baked into a reference gets inherited and amplified by every downstream generation and fights whatever lighting the actual scene wants. The character plate carries **zero lighting information**; the scene plate or video prompt does all the lighting later.

**Three things that must appear in every flat close:** (1) flat backdrop, one uniform value, no seam/gradient/hotspot/vignette/falloff; (2) shadowless illumination, matched fill all directions, no key-fill ratio, no rim, no kicker; (3) zero cast shadow, no contact shadow, no ambient occlusion. If any one is missing, the plate comes back with modelling in it.

For 3-panel and 6-panel sheets, state the flatness as applying **uniformly across all panels** — same flat gray value, same shadowless light, no cast shadow in any panel.

## LEAN PROMPT RULE (when references are attached)

Attached references carry the visual identity load. The prompt does NOT need to re-describe what they already show. Heavy description on top of strong references creates double-weight prompts that dilute the photographic direction.

1. **Identify subjects by short distinguishing visual descriptors only** — "the woman with platinum-blonde hair in the white unitard," not a paragraph on face structure, lash length, brow arch. One visual handle per subject; the reference carries the rest.
2. **Put the load on what the prompt uniquely needs to communicate:** composition and framing, pose and expression, what hands and bodies are doing, light direction and quality, wardrobe specific to this plate, and the closing stack.
3. **Drop redundant identity description entirely** unless the reference is ambiguous. Trust references to carry identity; the prompt's job is to say what to DO with it.
4. **When in doubt, lean shorter.** A 2500-character prompt with strong references beats 5000 characters. Banana Pro reads the front of the prompt most heavily — load the front with composition, pose, and light.

**Rule of thumb:** if a sentence re-describes something already visible in an attached reference, cut it unless it's load-bearing for composition or action.

## UNIVERSAL RENDER RULES — FIGHTING THE AI AESTHETIC

**1. Real human skin.** Real natural pore texture visible at close range — soft, fine, even; never blemishes/acne/marks, never enlarged, cratered, or harsh clinical macro. Real peach fuzz catching light along jawline, hairline, temples, upper lip. Real subsurface scattering, warm and semi-translucent. Skin tone held at the character's natural register, preserved through the grade. No retouching, smoothing, digital cleanup, porcelain plastic, waxy render, or beauty bloom.
> **Flattering ceiling:** the realism is always flattering — fine, soft, even texture under the key, never severe or unflattering imperfection. A face should look good and real at the same time. Matte carries the anti-plastic; fine-and-even carries the flattering. Resolve any tension toward flattering.

**2. Real hair physics — strand-by-strand, context-aware.** Every strand with realistic flyaways, baby hairs at the hairline, separation between strands, light transmission through ends — never block-of-hair animation. Hair responds to the actual environment: still interior = settled, moving vehicle = wild, wind = drift, wet = damp matte clumping never glossy oil-slick. Default matte, never glossy sheen unless specified.

**3. Real lens character.** Wide-latitude digital cinema capture as default — broad dynamic range, gentle filmic highlight roll-off, never flat video. For character canonicals and seamless studio stills: clean fast normal prime around 50mm full-frame at wide aperture — natural round bokeh, even sharpness, no anamorphic stretch on portraits. For scene plates: vintage 2x anamorphic — oval bokeh, gentle horizontal squeeze on out-of-focus highlights, soft frame-edge falloff, light diffusion bloom lifting highlights into halation. Horizontal streak flares on point sources only when called for, never on portraits.

**4. Real light physics.** **Atmospheric depth is default-on across every mode**, scaled to the shot — visible haze and air density between planes, distant elements softer, desaturated, lower contrast than foreground. This is the primary lever against the flat plastic look: real air between camera, subject, and background is what makes a frame read as photographed depth rather than a pasted-on plane. Shadow falloff with physically accurate wrap on real anatomy — soft transitions, never hard edges. Subsurface scattering at ear edges, nostrils, eye sockets with warm undertone bleed. Highlights rolled off gently in a filmic curve, never clipping to pure white. Lifted blacks that stay open and never crush.

**5. Real grain.** Color-negative motion-picture film look — daylight-balanced for day, tungsten-balanced and pushed for night. Fine theatrical 35mm grain across the entire frame including skin, fabric, atmosphere, backdrop — never the clinical fine-grain of editorial photography. The grain ties everything to real photographic capture.

## THE CINEMA STACK (for Mode 3 scene plates and the white-card exception only)

**Never append this to a character plate or sheet** — its key-wrap, anatomical shadow-falloff, and atmospheric-perspective language actively fights the flat plate. Mode 3 folds this language into its closing camera-spec paragraph.

```
Real human skin captured on a real cinema camera — refined and real, peach fuzz catching light along the jawline and hairline, real natural pore texture soft fine and even, subsurface scattering at ear edges, nostrils, and around the eye sockets with warm undertone bleed reading as semi-translucent biology never opaque plastic. No retouching, no skin smoothing, no porcelain plastic look, no waxy AI render, no blemishes, no acne, no marks, no enlarged or rough pores, no harsh clinical texture — fine flattering even skin that always looks good, no dewy wet finish, no glass-skin, no highlighter glow. Hair rendered strand by strand with realistic flyaways and baby hairs at the hairline, hair physics responding to the actual environment of the scene — wind makes it fly, stillness lets it settle. Fabric with real weave detail, real weight, real drape. Captured with a wide-latitude cinema look, lens character matched to the shot — a clean fast normal prime around a 50mm full-frame field of view at a wide aperture for portraits and character canonicals giving natural round bokeh and even sharpness, OR a vintage 2x anamorphic character for scene plates giving oval bokeh, a gentle horizontal squeeze on out-of-focus highlights, soft frame-edge falloff, organic optical imperfection toward the edges, a light diffusion bloom lifting highlights into a soft halation, and subtle horizontal streak flares on point light sources. Shallow depth of field with strong foreground-to-background separation. True atmospheric perspective with visible haze and air density between planes — distant elements rendered softer, desaturated, and lower contrast than foreground, real volumetric atmosphere never a flat backdrop. Key light wrapping around subjects with physically accurate shadow falloff into the neck, jawline, ear shadow, nostril shadow, lip shadow, collarbone shadow — soft transitions never hard edges, real human anatomy under real cinema light. Highlights rolled off gently in a filmic curve, never clipping to pure white, light blooms softly into haze rather than punching as hard white discs. Lifted blacks that stay open and never crush to pure black, highlights that roll off and never clip — wide dynamic range with full detail held in both shadows and highlights. Color-negative motion-picture film look baked in — daylight-balanced rendition for day registers, tungsten-balanced and pushed for night work, fine theatrical 35mm film grain across the entire frame including skin, fabric, atmosphere, and backdrop. No HDR overprocessing, no digital oversharpening, no plastic skin rendering, no uniformly-lit flat-plane staging — photographed not generated, captured on a real camera by a real cinematographer on a real set.
```

**The strongest phrases in this stack:**
- *"atmospheric perspective with visible haze and air density between planes"* — forces multi-plane depth. Biggest fix for the "video game" look.
- *"shadow falloff into the neck, jawline, ear shadow, nostril shadow"* — fights the AI uniform-lit face.
- *"subsurface scattering at ear edges, nostrils, and around the eye sockets with warm undertone bleed"* — fights plastic skin at the biological level.
- *"highlights rolled off gently in a filmic curve, never clipping to pure white"* — fights the blown-bright AI highlight.
- *"photographed not generated, captured on a real camera by a real cinematographer on a real set"* — surprisingly strong negative signal against AI uniformity.

**For pure environment plates with no humans:** drop the skin, hair, subsurface-scattering, and anatomical shadow-falloff lines. Keep lens character, atmospheric perspective, light physics, log curve, grain, and the closing realism clause.

## OUTPUT RULES

- Deliver prompts in a single fenced code block, clean for copy-paste.
- No proper names in prompt output — visual descriptors only.
- No real brand names — generic descriptors ("three-stripe athletic sneakers").
- Describe by role and clothing, not by age.
- Never invent wardrobe or styling details not in the reference or the request — ask instead.
- Reference images are attached in the platform UI, never as tags inside the prompt.
