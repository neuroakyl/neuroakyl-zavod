# Контент-завод

Человек говорит, что нужно. Всё, что можно сделать без него, делаешь сам. Его решения — только на точках «да» (ниже).
Настройки человека — `local.md`. Его нет — выполни `УСТАНОВКА.md`.
Всё о человеке — его цифровой мозг (`модули/мозг.md`). Каждый модуль читает из мозга только свои файлы. Мозга нет — сначала собери его.

## Какой путь
Определи по просьбе, не спрашивай, и открой только нужный файл из `модули/`:

| Что просят | Путь |
|---|---|
| Ролик, где говорит человек, но он не снимается | темы → сценарий → аватар → монтаж → выкладка |
| Человек снял себя, есть запись | сценарий не нужен: монтаж (живая съёмка) → выкладка |
| Креативный, рекламный, сюжетный ролик без спикера | креатив → монтаж → выкладка |
| Контент-план на неделю или месяц, «что снимать», «куда выкладывать» | контент-план (он вызывает стратегию, темы, сторис) |
| Где брать темы | темы |
| Сторис: что выкладывать сегодня, серия прогрева | сторис |
| Цель контента, как продавать без «купи», как ранжируют площадки | стратегия |
| Карусель | сценарий → карусели → выкладка |
| Настроить завод под человека, собрать или дополнить мозг | мозг → мозг-интервью |

| Модуль | Файл | Что нужно |
|---|---|---|
| Цифровой мозг: схема базы и кто что читает | `модули/мозг.md` | — |
| Интервью, по которому собирается мозг | `модули/мозг-интервью.md` | навык instagram-parser по желанию |
| Стратегия: цели, сигналы площадок, прогрев | `модули/стратегия.md` | только Claude |
| Контент-план на неделю и месяц | `модули/контент-план.md` | только Claude |
| Сторис: типы, ритм, серии прогрева | `модули/сторис.md` | только Claude |
| Темы | `модули/темы.md` | Apify по желанию |
| Сценарий: правила, хуки, форматы, разметка под монтаж, самопроверка | `модули/сценарий.md` (папка `модули/сценарий/`) | только Claude |
| Аватар | `модули/аватар.md` | коннектор HeyGen |
| Монтаж: вертикаль, горизонталь, живое, сгенерированное | `модули/монтаж.md` | навык montazh |
| Креативные ролики | `модули/креатив.md` | ключ Kie |
| Выкладка | `модули/выкладка.md` | ключ Buffer |
| Карусели | `модули/карусели.md` | Node |
| Telegram-бот, управление с телефона | `модули/бот.md` | токен бота |

Нет нужной части — поставь её сам: `python3 install.py --chasti <часть>`, а ключ попроси по `УСТАНОВКА.md`.

## Точки «да»
1. **Тема** из предложенных с оценкой.
2. **Сценарий.**
3. **Деньги.** Перед любой платной генерацией называешь, что и сколько стоит, и ждёшь суммы. Озвучка аватаром уже утверждённого сценария — без вопроса, если в `local.md` не сказано иначе.
4. **Вид ролика**: стоп-кадры или лист кадров, до дорогого шага.
5. **Готовый ролик** перед выкладкой. Что выкладывать без вопроса, решает только `local.md`.

Точка «да» — одно короткое сообщение с твоим решением и причиной. Не меню. Человек занят, не задавай того, что можешь решить сам.

## Правила
- Готово — это файл, который ты посмотрел, или пост со ссылкой. «Запрос принят» не считается.
- Лимиты и запреты живут в коде (`kreativ.py`), а не в обещаниях.
- Ключи только в `.env`. Не печатай их, не проси присылать в чат.
- Ролик живёт в своей папке. Завод и движок монтажа им не засоряются, в них идёт только общее.
- Объём важнее идеала: лучше выложенный ролик, чем ещё один круг правок.
