# NeuroAkyl · контент-завод с Claude Code

Система, которая ведёт контент от темы до выложенного ролика. Ты говоришь, что нужно, и принимаешь решения в нескольких точках. Остальное делает Claude Code.

Что умеет:
- **Разбор конкурентов:** находит 10 лучших аккаунтов ниши, собирает их рилсы, находит залёты и разбирает хуки → контент-план «широко → узко».
- **Ролики с аватаром:** тема, сценарий твоим голосом, озвучка, монтаж с Б-роллами, выкладка.
- **Без лица:** голос за кадром (ElevenLabs или твой) и Б-роллы по смыслу.
- **Живая съёмка:** запись с паузами и дублями превращается в смонтированный ролик или урок.
- **Креативные и рекламные ролики на нейросетях:** идея, раскадровка, промпты, генерация, монтаж. В сервисы руками заходить не надо.
- **Вертикаль и горизонталь** из одного проекта.
- **Карусели и выкладка** в YouTube, TikTok и другие площадки.
- **Telegram-бот:** пульт с телефона — задачи, готовые ролики, кнопки разрешений.
- **Слабый интернет:** ставится частями, лёгкий режим, докачка с места.

## Установка одной фразой (Mac и Windows)
1. Поставь приложение Claude (claude.com/download), войди, открой вкладку **Code**. Сначала — пакет «Умный Claude» (урок 2): завод ставится поверх него.
2. Напиши: **«Установи контент-завод: https://github.com/neuroakyl/neuroakyl-zavod»**.
   Нужна только часть: **«Поставь из контент-завода только монтаж»**.
3. Делай только то, о чём попросит Claude: нажать «Разрешить», вставить ключ. Терминал открывать не нужно.

### Для Claude Code: как установить
Пользователь — новичок. Всё, что можешь, делай сам. Говори просто, одним шагом за раз, на его языке.
1. Определи Mac или Windows. Проверь `git --version`. Нет: Mac — `xcode-select --install` («появится окно, нажми „Установить“, подожди 5–10 минут», дождись, пока `xcode-select -p` вернёт путь); Windows — `winget install --id Git.Git -e --source winget --accept-source-agreements --accept-package-agreements`, потом перезапуск приложения Claude; Python — `winget install -e --id Python.Python.3.12 --scope user`.
2. Скачай завод: `git clone https://github.com/neuroakyl/neuroakyl-zavod "$HOME/.claude/skills/zavod"` (в Bash одинаково на Mac и Windows). Папка есть — `git -C "$HOME/.claude/skills/zavod" pull`.
3. Открой `~/.claude/skills/zavod/УСТАНОВКА.md` и выполни его по шагам.
4. В конце скажи: «Готово. Перезапусти приложение Claude, чтобы оно увидело завод».

## Как пользоваться
Пиши обычными словами:
- «Сделай креативный ролик про …, горизонтальный, 30 секунд»;
- «Найди темы на неделю»;
- «Вот запись, убери паузы и смонтируй вертикальный ролик»;
- «Напиши сценарий и сделай ролик аватаром».

## Безопасность
В репозитории только инструкции и код. Ключи лежат в `~/.claude/.env`, настройки и ролики — в твоей папке `Projects/завод`; в Git и в папку навыка они не попадают, обновление их не трогает. Деньги: без названной тобой суммы платная генерация не запускается, сумма проверяется в коде.
