# Без лица: голос за кадром + Б-роллы

Формат для тех, кто не хочет в кадр и не платит за аватар: голос ElevenLabs (или своя запись голоса) и кадры по смыслу.
Главный рычаг качества — Б-роллы: метафора, а не картинка в лоб, только качественные кадры, смена каждые 1,5–3 с.

1. **Папка.** `ролик/rolik.py new "тема" --tip bez-lica [--format horizontal]` → `Projects/завод/ролики/ГГГГ-ММ-ДД-тема/`.
2. **Сценарий** → `сценарий.md` (модуль `сценарий.md`, раздел «Текст»). Точка «да».
3. **Голос.** Навык montazh: `инструменты/golos.py <текст> <папка ролика> --voice <голос из local.md> --lang <язык>` → `assets/voice.wav`
   и слова. Кыргызский: `--lang ky` (скрипт сам ставит модель `eleven_v4` и скорость 1.2 — ElevenLabs читает ky медленно; без `--lang ky` выйдет акцент), тайминги слов — `words.py` / `words_vad.py` (Whisper кыргызский не знает).
   Тариф ElevenLabs: на бесплатном через API работают только встроенные голоса (Adam, Brian…), свой клон и коммерческое использование —
   с платного Starter. Остаток символов — до озвучки, длинный сценарий может не влезть в месяц.
   Нет ключа ElevenLabs — человек может наговорить сам на телефон: запись → `исходники/`, дальше как живая съёмка.
   Озвучка утверждённого сценария — без отдельного вопроса, если в `local.md` не сказано иначе (символы подписки, не деньги сверху).
4. **Б-роллы.** montazh `инструменты/broll.py all "<запрос по смыслу фразы>" <папка>/исходники/б-роллы` — бесплатно (Mixkit без ключа,
   Pixabay с бесплатным ключом, YouTube — только если человек разрешил в `local.md`). Свои фото и видео — `Projects/завод/медиатека/`.
   Не хватает кадра — картинка Kie (`креатив.md`, платно, точка «деньги»). Лист превью — на проверку, если человек просил.
5. **Монтаж** — навык montazh, композиция `Klipy`: голос, Б-роллы по словам, подписи, музыка (модуль `монтаж.md`).
6. **Черновик до денег:** `rolik.py zaglushka <папка>` собирает тот же ролик с голосом-заглушкой — показать структуру и темп.
