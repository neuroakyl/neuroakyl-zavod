# Telegram-бот: пульт завода с телефона

Человек пишет своему боту в Telegram — отвечает Claude Code на его компьютере, с доступом ко всему Projects и заводу.
Сюда приходят готовые ролики, вопросы на точках «да» и **кнопки разрешений** («разрешить / запретить»), когда Claude нужно действие
вне автономного режима. Основа — официальный канал Claude Code (плагин `telegram@claude-plugins-official`, research preview,
code.claude.com/docs/en/channels). Скрипт: `бот/bot.py`.

**Честно о границах:** бот работает, пока компьютер включён, не спит и открыто окно бота. Компьютер выключен — бот молчит.
Тариф Claude — Pro или Max. Работа плагина на Windows официально не заявлена — проверяется в тесте (`тест-windows.md`).

## Установка (Claude делает сам, человек — 3 действия)
1. **Бот.** Человек: Telegram → @BotFather → `/newbot` → имя → ник на `bot` → копирует токен. Ты открываешь файл ключей
   (Mac `open -e ~/.claude/.env`, Windows `notepad "$USERPROFILE\.claude\.env"`): «вставь токен после TELEGRAM_BOT_TOKEN=, сохрани, закрой».
2. **Программы.** `bot.py proverka` → чего нет, ставь сам: Claude Code для терминала, Bun, `claude plugin install telegram@claude-plugins-official`.
3. **Настройка.** `bot.py nastroit`: проверит токен, попросит человека нажать «Старт» у бота, запомнит его chat id, пришлёт тестовое
   сообщение. Плагин выключается для всех чатов и включается только в окне бота: иначе каждый новый чат перехватывает бота (проверено на практике).
4. **Запуск.** `bot.py zapusk` — откроется окно (Терминал / командная строка) с Claude. Скажи: «это окно — бот, не закрывай, можно свернуть».
   Первый запуск может спросить «доверять папке?» — нажать Enter (это только в окне, в Telegram не приходит).
5. **Привязка (один раз, делает человек).** Он пишет боту любое сообщение → бот отвечает кодом → в окне бота человек вводит
   `/telegram:access pair <код>`, затем `/telegram:access policy allowlist`. Теперь бот слушает только его. Привязку ты не делаешь:
   это замок доступа.
6. **Автозапуск.** `bot.py avtozapusk` — окно бота откроется само при входе в компьютер. Скажи про сон компьютера (скрипт напомнит).
7. **Проверка.** Человек пишет боту «сделай черновой ролик» → приходит видео. Это и есть «готово».

## Как бот работает
- **Ответ сразу.** Первым делом коротко «✅ Взял: <задача>», потом работа. Долгое (ролик, разбор конкурентов) — фоновому помощнику,
  чтобы бот оставался свободным для следующего сообщения.
- **Ролики в чат.** Готовое видео — `reply` с `files` (до 50 МБ, уходит документом). Больше 50 МБ — навык montazh
  `инструменты/telegram.py <видео> "подпись"` сожмёт копию до 720p. Из обычного чата в приложении Claude — тот же `telegram.py`.
- **Разрешения кнопками.** Пакет «Умный Claude» включает автономный режим: Claude не спрашивает по мелочам. Где спрашивает
  (Bash, запись файлов вне правил) — в Telegram приходит запрос с кнопками; ответить можно и в окне, и с телефона, кто первый.
  Деньги, выкладка, удаление — точки «да» словами, как в чате.
- **Файлы от человека.** Фото приходят сами; видео и документы — `download_attachment` (Telegram даёт боту до 20 МБ).
  Сразу **переноси** в папку ролика или `Projects/материалы/входящие/` и скажи куда.
- **Слабый интернет.** Видео тяжелее 20 МБ человек присылает сжатым (обычным видео, не файлом) или кладёт на компьютер сам.

## Если бот молчит
1. Окно бота открыто? Нет — `bot.py zapusk`.
2. Бот «печатает», но не отвечает — канал не поднялся: закрыть окно, открыть снова.
3. Ответил другой чат или никто — плагин включился для всех: `bot.py nastroit` ещё раз (вернёт выключение для всех).
4. Компьютер уснул — настройки питания (`bot.py avtozapusk` подсказывает где).

## Без бота
Remote Control: в приложении Claude на компьютере включить Remote Control, на телефоне — приложение Claude, тот же чат.
Проще бота, но без кнопок в Telegram и без роликов в чат. Хорошо как первый шаг, пока бот не настроен.
