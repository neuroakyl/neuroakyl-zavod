# Карусели

Один шаблон и меняющийся текст: `карусели/render.js`, `карусели/template.html`, размер 1080×1350.
Первый раз в папке карусели: `npm install playwright && npx playwright install chromium`. Запуск: `node render.js slides.json out`.

`slides.json`: `handle`, `hint`, `slides[]` с `type` (`hook`, `point`, `insight`, `cta`), `kicker`, `title`, `body`. Ключевое слово в `[[ ]]` станет акцентом.
Цвета бренда — в `slides.json` полем `"cveta": {"bg": "#0D0E0F", "ink": "#F2F0EA", "lime": "#C8FF00"}` (имена — переменные
в начале `template.html`), значения бери из `мозг/бренд.md`. **Файлы навыка не правь** (`template.html`, `render.js`): правка ломает
обновление завода. Папка карусели — `Projects/завод/ролики/ГГГГ-ММ-ДД-тема/`, там `slides.json` и `out/`.

Из плана: пункт `K…` (`plan.py dalshe --format karusel`), после рендера и просмотра — `plan.py otmetit K01 gotov --fail <папка out>`.
Текст слайдов пиши по `модули/сценарий/форматы/карусель.md`. Коротко: обложка — хук 5–8 слов и разрыв любопытства, одна мысль на слайд, до 12 слов в заголовке, 8–10 слайдов, последний — призыв с кодовым словом. Посмотри каждый PNG, прежде чем отдавать.
