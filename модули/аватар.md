# Аватар

Коннектор HeyGen в Claude: вход через аккаунт HeyGen, ключ не нужен, тратит кредиты тарифа. Человек снимает себя один раз и подключает
коннектор в настройках claude.ai (урок 6, прямо перед первым роликом с аватаром).

**Настройки вызова не собирай руками, бери из `аватар/heygen.py`.** Без явного движка голоса HeyGen сам выбирает движок для клона,
и кыргызский звучит с акцентом. Так было у двух учеников подряд.

## Один раз: аватар и голос
1. `list_avatar_groups` → `list_avatar_looks` → покажи человеку луки, он выбирает. `list_voices` → его голос (клон).
   Запиши id лука, id голоса и язык в `local.md` (раздел «Аватар»), дальше не спрашивай.
2. **Пробный ролик 10–15 с** на языке человека с настройками ниже. Человек слушает: акцент, скорость, похож ли голос.
   Это одна точка «да», дальше без вопросов. Акцент остался — смотри «Если звучит не так».

## Каждый ролик
1. Сценарий утверждён → настройки:
   `py аватар/heygen.py parametry --avatar <лук> --voice <голос> --lang <язык> [--format horizontal] --papka <папка ролика>`
   Вставь в `script` утверждённый текст дословно и вызови `create_video_from_avatar` ровно с этим JSON.

   | Поле | Значение | Зачем |
   |---|---|---|
   | `voiceSettings.engine_settings` | `{"engine_type": "elevenlabs", "model": "eleven_v4"}` | без него — акцент. Для ky у HeyGen только ElevenLabs v3/v4, v4 живее |
   | `voiceSettings.locale` | **не задавать** | «оригинальный акцент» голоса; любой locale ломает кыргызский |
   | `voiceSettings.speed` | `1.2` | кыргызский у ElevenLabs читается медленно |
   | `engine` | `{"type": "avatar_iii"}` | по умолчанию HeyGen берёт Avatar 6 Turbo; III — самый дешёвый (около 4 кр./мин), монтаж его прячет |
   | `resolution` | `1080p` | без него III/IV/V отдают 720p |
   | `aspectRatio` | `9:16` (Reels) или `16:9` | |
   | `caption` | `{"file_format": "srt"}` без `style` | субтитры отдельным файлом; вшитые мешают монтажу |
   | фон | сплошной, однотонный | монтаж вырезает или перекрывает |

2. `get_video` раз в 30 с. Готово → **сразу** скачай mp4 и srt в `исходники/` папки ролика: ссылки живут около 7 дней.
3. Темп: `py аватар/heygen.py temp исходники/<файл>.srt --lang <язык>`. Скорость из настроек HeyGen применяется не всегда (у нас 19.10.2026 не
   применилась). Скрипт скажет, ускорять ли на монтаже и на сколько (не больше ×1,25). Ускорил — послушай сам.
4. Посмотри кадры и послушай начало и конец. **Готово — когда файл открылся, голос совпал с текстом и без акцента.** «Задача принята» не считается.
5. Монтаж: `модули/монтаж.md`. Слова для кыргызского берутся из srt HeyGen или `words.py`: Whisper кыргызского не знает.

## Если звучит не так
| Что слышно | Причина | Что делать |
|---|---|---|
| Акцент, «иностранец читает по-кыргызски» | не задан `engine_settings`, HeyGen взял свой движок голоса | заново с JSON из `heygen.py`. Голос «не совместим с движком» — клон делался не под ElevenLabs: заново клонировать в HeyGen или озвучить в ElevenLabs и подать звук (ниже) |
| Медленно, «читает» | скорость не применилась | `heygen.py temp` → ускорить на монтаже |
| Голос не похож на человека | клон с плохой записи | перезаписать образец: петличка, тихая комната, 1–3 мин живой речи |
| Слово произносит не так (бренд, английское слово) | ElevenLabs не знает слова | написать в сценарии, как слышится («Клод Код»), или глоссарий HeyGen `brandGlossaryId` |
| Губы не попадают | звук подан файлом m4a | HeyGen берёт mp3, m4a не принимает |

Свой звук вместо текста (своя запись, голос ElevenLabs из `модули/без-лица.md`): mp3 → `create_asset_upload` → `complete_asset_upload` →
`create_video_from_avatar` с `audioAssetId` вместо `script` и `voiceId`. Голос тогда не пересчитывается, скорость задаёт сам звук.
`create_speech` (голос без видео) кыргызский не берёт: для ky сплошной голос делай видео на Avatar III или через ElevenLabs.

## Деньги
- Перед первым роликом назови цену с текущего тарифа (в HeyGen, не по памяти). Ориентир: III около 4 кр./мин, IV около 31, V около 48: V в ~11 раз дороже III.
- Дорогой аватар (IV, V) — только на кадры с лицом, не больше 20–30% ролика: сплошной голос целиком, лицо на V кусками
  (навык montazh: `segs.py` режет звук по словам, `compose.py` ставит куски на места). Остальное — Б-роллы.
- Бесплатный тариф HeyGen — только 720p и мало кредитов: для Reels нужен платный.

Дальше — `модули/монтаж.md`, материал: файл аватара и srt.
