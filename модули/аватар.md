# Аватар

Коннектор HeyGen в Claude: вход через аккаунт HeyGen, ключ не нужен, тратит кредиты тарифа. Человек подключает его
в настройках claude.ai (урок «Аватар HeyGen», прямо перед первым роликом с аватаром).

**Все вызовы, голос и план лица — только из `аватар/heygen.py`.** Руками JSON не собирай: у учеников это ломалось трижды
(акцент без `engine_settings`; голос взят из `list_voices`; дорогой движок по умолчанию).

**Схема (Бобби, 22.11.2026):** голос всего ролика — в самом HeyGen, голос аватара на ElevenLabs v4 → лёгкое ускорение →
лицо 20–30% ролика (начало или с 3-й секунды, 1–2 раза в середине, призыв в конце) на Avatar 6 Turbo по готовому звуку →
остальное Б-роллы. Голос сплошной, поэтому кажется, что аватар говорит всё время.

## Главная грабля: откуда голос
`list_voices` коннектора показывает **только голоса HeyGen Voice** — кыргызский они не знают, ElevenLabs v4 их не берёт:
озвучка падает или выходит с акцентом. Рабочий клон стоит **в настройке аватара**: `list_avatar_groups` → `default_voice_id`.
`heygen.py` берёт голос только оттуда и не пустит голос из `list_voices`.
`create_speech` для кыргызского тоже не подходит (он только на HeyGen Voice).

## Один раз: аватар, голос, проба
1. Человек в HeyGen (сайт, руками): аватар — Avatars → Create → Digital Twin; голос — Voices → клон из записи 20+ минут
   (петличка, тихая комната, живая речь); в аватаре Voice → этот клон. Это и есть «голос в настройке аватара».
2. `list_avatar_groups` (private) и `list_voices` (private) → сохрани ответы целиком в `groups.json` и `voices.json` →
   `py аватар/heygen.py nastroit --gruppy groups.json --golosa voices.json --gruppa <имя> --lang ky`.
   Скрипт сам скажет, если голос не выбран или он HeyGen Voice, — передай человеку его текст.
3. `list_avatar_looks` группы → покажи луки (`show_avatar_looks`), человек выбирает → `nastroit … --look <id>`.
   Всё лежит в `завод/аватар.json`, дальше не спрашивай.
4. **Проба 5–10 с:** `py аватар/heygen.py test --tekst проба.txt` (1–2 фразы) → `create_video_from_avatar` ровно с этим JSON.
   ≈3–4 кредита. Человек проверяет: голос похож, без акцента, темп; лицо живое, губы попадают. Вердикт — в `local.md`.

## Каждый ролик
1. **План до генерации:** `py аватар/heygen.py plan --tekst сценарий.txt --papka <папка>` — какие куски на лицо, доля, кредиты.
   Назови человеку итог одной строкой («голос ≈4 кр., лицо 4 куска 15 с ≈8 кр.»).
2. **Голос:** `py аватар/heygen.py golos --tekst сценарий.txt --papka <папка>` → `create_video_from_avatar` с этим JSON
   (Avatar III, только звук: без явного `avatar_iii` коннектор возьмёт Avatar 6 и съест в 5 раз больше).
   `get_video` → скачай mp4 и srt в `исходники/` сразу (ссылки ~7 дней) → звук: `ffmpeg -i golos.mp4 -vn -ac 1 -ar 44100 -b:a 192k golos.mp3`.
3. **Лёгкое ускорение:** `heygen.py temp golos.srt` → `heygen.py uskorit golos.mp3 --k K` → `heygen.py slova golos.srt --k K`
   (words.json; точнее — montazh `words.py` по ускоренному треку).
4. **План по точным словам:** `heygen.py plan --words words.json --track golos-xK.mp3 --papka <папка>` — он печатает команду нарезки.
5. **Нарезка:** выполни эту команду (montazh `инструменты/segs.py …`): mp3-куски `lico/seg-N.mp3`. Больше 30% — откажет.
   Кредиты segs.py считает по Avatar V — верь цифре из `plan`.
6. **Загрузка (бесплатно):** `heygen.py zagruzka lico` → `create_asset_upload_batch` с этим JSON → ответ целиком в `lico/zagruzka.json` →
   `heygen.py put lico/zagruzka.json --papka lico` (PUT на S3 HeyGen) → `complete_asset_batch` → `get_asset_batch`, пока все `completed`.
7. **Лицо:** `heygen.py lico --aktivy lico/zagruzka.json --papka lico` → по одному `create_video_from_avatar` на кусок.
   Готовое — `lico/v/N.mp4` (N = номер seg-N). Губы совпадают, голос не пересчитывается.
8. **Сборка:** montazh `compose.py` ставит куски на места поверх голоса, дальше `модули/монтаж.md`: Б-роллы, подписи, музыка.
9. Посмотри ролик целиком. **Готово — когда лицо живое, губы попадают, голос без акцента.** «Задача принята» не считается.

## Модель лица
| Модель (`--model`) | Кредитов/мин | Когда |
|---|---|---|
| `6turbo` — Avatar 6 Turbo | 20 | по умолчанию: новее и живее V, есть на Creator |
| `6pro` — Avatar 6 Pro | 40 | крупные планы, если 6 Turbo не устроил; тариф Pro и выше |
| `v` — Avatar V | 48 (замер ≈60) | только если человек сам попросил |
Avatar III и IV в кадр не ставим: картинка неживая. III — только проход за голосом.

## Если звучит или выглядит не так
| Что видно | Причина | Что делать |
|---|---|---|
| Озвучка падает: «voice not compatible with engine» | голос взят из `list_voices` (HeyGen Voice) | `nastroit` заново: голос из аватара |
| Акцент, «иностранец читает по-кыргызски» | не задан `engine_settings` / locale | JSON только из `heygen.py`; locale не ставить |
| Аватар неживой, деревянный | в кадре Avatar III или IV | лицо только `lico` (6 Turbo / 6 Pro) |
| Медленно, «читает» | скорость HeyGen не применилась | `temp` → `uskorit` до нарезки |
| Голос не похож на человека | клон с плохой или короткой записи | перезаписать: 20+ мин, петличка, тихая комната |
| Слово произносит не так (бренд, английское) | ElevenLabs не знает слова | писать, как слышится («Клод Код»), или `brandGlossaryId` |
| Губы не попадают | m4a или кусок обрезан посреди слова | только mp3; резать `segs.py` по словам |
| `put` упал на 403 | ссылка загрузки старше суток | `zagruzka` → новый `create_asset_upload_batch` |
