# Сценарий

Сценарий короткого ролика (Reels, Shorts, TikTok) или текст карусели. Цель: человек прочитал и снимает с первого раза,
без «сделай живее». Порядок ниже обязателен: пропущенный шаг и есть причина слабого текста.

## Что открыть
| Файл | Когда |
|---|---|
| `сценарий/правила.md` | всегда, целиком |
| `сценарий/хуки.md` | всегда, на шаге 6 |
| `сценарий/форматы/<формат>.md` | один файл под формат ролика (таблица в шаге 3) |
| `сценарий/разметка.md` | всегда, если дальше монтаж |
| `сценарий/проверка.md` | всегда, до показа человеку |
| `сценарий/источники.md` | только если спросили, откуда правило |

## Порядок работы

**Вход:** мозг человека + тема + карточка единицы из `стратегия.md` (цель, кому, формат, рубрика, мост, призыв).
Тему выбирают в `темы.md`, сюда она приходит утверждённой. Карточки нет — заполни сам цель, формат и призыв (шаги 2–3)
и покажи их одной строкой в выдаче.

### 1. Мозг: что читать
Папка `мозг/` человека, путь — строка «Мозг:» в `local.md`, схема полей — `мозг.md`. Поля ищи grep-ом по заголовку
`## Поле`, файлы целиком не читай (кроме `запреты.md`).

| Файл и поле | Что берёшь | Поля нет или пусто |
|---|---|---|
| `голос.md` → `## Эталоны` | 2–3 текста **того же формата**; если у эталонов есть просмотры — самый просматриваемый и один провал для контраста. Нужного формата или языка нет — бери ближайший по цели и сверяй только длину фраз и плотность деталей, не число слов. Нет ни одного эталона на языке ролика — попроси один и пометь «голос не сверен» | работай без них, в выдаче пометь «голос не сверен»; попроси 3 ссылки на свои ролики или 3 голосовых по минуте |
| `голос.md` → `## Как говорит`, `## Никогда не говорит`, `## Правки` | обороты, длина фраз, «ты» или «вы», как начинает и кончает; запретные слова; прошлые правки | выведи голос из эталонов сам |
| `аудитория.md` → `Боли`, `Страхи и возражения` | слова зрителя дословно: из них лучшие хуки | хук строй на теме, в выдаче пометь «боли не сверены» |
| `продукт.md` → `## Кодовые слова` | слово и что за него получает зритель | спроси одним вопросом: «что дашь человеку за слово в комментариях?» Ответ запиши в поле |
| `кто-я.md` → `## Доказательства`, `## Границы личного` | цифры для «я сделал» и что из жизни нельзя упоминать | без личных цифр, ничего личного |
| `истории.md` | для формата «история» и для живой детали в любом ролике | для истории спроси: «расскажи один случай: что было, что сделал, чем кончилось» |
| `позиция.md` → `## Враг` | с чем спорит ролик: миф, старый способ | пропусти |
| `доноры.md` | хуки и цифры 1–2 чужих залётов на эту тему | шаг 4 сделай поиском или пропусти и пометь |
| `запреты.md` | всё, целиком | спроси: «что нельзя говорить и обещать?» Ответ запиши в файл |
| `снятое.md` | grep по ключевым словам темы. Повтор — та же главная мысль: стоп. Тот же предмет под другой мыслью можно, пометь в выдаче | пропусти |
| `local.md` (не мозг) | язык ролика; записана ли концовка отдельно и вклеивается на монтаже | язык — по просьбе или по языку эталонов |

Эталоны дают голос, длину и меру конкретики. **Каркас из эталона не копируй**: модель повторяет скелет образца сильнее,
чем слушает правила, и все ролики выходят одинаковыми. Структуру даёт файл формата и залёт донора.

### 2. Цель ролика
Берёшь из карточки. Нет — определи сам и напиши в выдаче одной строкой. Одна единица — одна цель.

| Цель | Когда | Что меняется в сценарии |
|---|---|---|
| **Охват** | «ого»-факт, чужой успех, скрытый механизм, спорное | хук на массового зрителя; продукт только мостом в последней фразе; призыв — переслать или слово за бесплатный материал |
| **Доверие** | разбор, ошибка, список, кейс, мнение эксперта | хук на свою аудиторию из её болей; видна экспертиза и цифры; призыв — сохранить или слово за материал |
| **Продажа** | процесс, результат клиента, «до и после», продукт в деле | боль → картинка из жизни → как снимается → результат; призыв — кодовое слово, предложение в директе |
| **Сообщество** | мнение, спорный вопрос, «а как у вас» | хук-вопрос с предметом; призыв — вопрос, на который легко ответить |

Продажа в ленте не звучит как реклама: ролик отдаёт пользу, предложение уходит в личку за кодовое слово.

### 3. Формат
| Формат | Файл |
|---|---|
| Говорящая голова или аватар: факт, мнение, механизм | `форматы/голова.md` |
| Живая съёмка эксперта: сам в кадре, на месте работы | `форматы/живая-съёмка.md` |
| История: случай, клиент, свой путь | `форматы/история.md` |
| Список: N ошибок, признаков, способов | `форматы/список.md` |
| Разбор: чужой ролик, кейс, «почему это сработало» | `форматы/разбор.md` |
| Процесс: «как сделано», инструкция, показ в деле | `форматы/процесс.md` |
| Карусель: текст слайдов | `форматы/карусель.md` |

Не знаешь — бери голову или аватар. Формат можно совместить с другим (история в живой съёмке). Тогда каркас бери из
формата содержания (история), а правила съёмки — из формата подачи (живая съёмка).

### 4. Референс-хуки
Выпиши 5–10 первых фраз залетевших роликов на эту тему или с этим типом хука: из `доноры.md`, комментариев, поиска
(если есть интернет; Apify и платные сервисы — только с согласия человека).
Тип хука повторяй, слова — свои. Не нашёл — пропусти и отметь в выдаче.

### 5. Одна мысль
Допиши строку: «Зритель уйдёт с тем, что ___». До 15 слов, без «и». Не пишется одной строкой — в теме две мысли:
выбери одну, вторую предложи отдельным роликом.

### 6. Хуки
По `хуки.md`: 6–8 вариантов минимум трёх типов → оценка по шкале оттуда → лучший и два запасных.

### 7. Черновик
По каркасу файла формата и правилам из `правила.md`. Сначала выпиши фразы столбиком: одна строка = одна фраза = один план.

### 8. Живой текст
Прогони штампы (`правила.md`, правило 12), прочитай текст вслух про себя. Где споткнулся — перепиши.

### 9. Разметка под монтаж
По `разметка.md`: план, Б-ролл, текст на экране, акцент на каждую фразу.

### 10. Самопроверка
По `проверка.md`: баллы с цитатой-доказательством на каждый пункт, порог 85. Не дотянул — перепиши по таблице оттуда
и посчитай заново, не больше двух кругов.

### 11. Отдать человеку
Одно сообщение, без «вот сценарий»:

```
<Тема> · <формат> · цель: <охват/доверие/продажа> · ~<N> с, <N> слов · <балл>/100
Мысль: <строка из шага 5>

Хук: <фраза>   Запасные: 1) <…> 2) <…>

<текст сценария столбиком, как читать вслух>

Призыв: <фраза>  (или «концовка готовая, вклеит монтаж»)
Обложка: <3–5 слов>
Слабое место: <одна строка: что можно усилить и чем>
Сверить до записи: <факты из памяти, если есть>
Пометки: <пересечение со снятым, допущения; если нет — строку убрать>
```
Слова считай по `голос.txt`, как звучит.

Разметку под монтаж не показывай в сообщении: положи файлы в папку ролика (`разметка.md`, раздел «Что отдать»).
После «да» сценарий не переписывай без просьбы, правки человека окончательные. Каждую правку, которая повторяется,
запиши в `мозг/голос.md` или `мозг/запреты.md`: это и есть рост качества от ролика к ролику.
