# Профессиональный клон голоса (ElevenLabs PVC)

Качество по умолчанию — максимальное. Клон копирует всё: тембр, манеру, микрофон, комнату и обработку.
Плохая запись или неверная настройка = плохой голос во всех роликах навсегда. Правила проверены на голосе Бобби (28.11.2026).

## 1. Запись (делает человек)
- **Что:** 30–60 минут (лучше час) живой речи на ОДНОМ языке — на том, на котором будут ролики. Не читать с листа — рассказывать по темам
  (детство, первые деньги, работа, смешной случай, совет новичку, мечты), разной подачей: спокойно, энергично, как эксперт.
- **Как говорить:** стоя, громко, «в камеру», как в живом ролике. Клон повторит манеру: спокойное чтение = ровный «роботский» голос.
- **Микрофон:** петличка на груди, 15–20 см ото рта, не трётся об одежду. Один и тот же микрофон и место на всю запись И на верификацию.
- **Чем писать на Mac:** приложение «Диктофон». Перед записью: Системные настройки → Звук → Вход → петличка;
  Диктофон → Настройки → Качество звука → **«Без потерь»** (по умолчанию стоит «С потерями» — так нельзя);
  Пункт управления → режим микрофона «Стандартный» (не «Изоляция голоса»). Кнопку «Улучшить запись» не нажимать.
- Куски по 5–15 минут — удобно. Ничего не вырезать и не редактировать: паузы и дыхание — часть живой речи.

## 2. Чистка (делает Claude, Auphonic)
Только мягко. Сила подавления на максимум (100 дБ) даёт «чуть роботизированный» голос — проверено.
Параметры Auphonic API (`algorithms`), выход **FLAC** (не mp3):
```
filtering: true, filtermethod: "autoeq"          # тембр + де-эссер, без bwe и studiovoice
denoise: true, denoisemethod: "dynamic", denoiseamount: 15, deverbamount: 15   # шум и эхо комнаты умеренно
leveler: false, compressor: "auto"               # не давить живые перепады громкости
normloudness: true, loudnesstarget: -18, maxpeak: -3
```
- Нельзя: `studiovoice`, `speech_isolation` и сила 0 (=100 дБ) — перерисовывают голос; резка пауз и вдохов.
- Бесплатный Auphonic вставляет заставку в начало и мелодию в конец — обрезать по сдвигу огибающей, длина = исходнику.
- Скачивание результата: пробелы в имени файла кодировать (`%20`), иначе curl падает.
- Перед прогоном всего — проба 45 с: сырое / чистка, одной громкости, человек слушает и выбирает.

## 3. Создание клона (на сайте ElevenLabs, руками — так надёжнее)
Voices → Create → **Professional Voice Clone** (не Instant). Заполнить ВСЁ:
- **Voice name** — например «Bobby KG voice».
- **Language used in audio samples** — язык записи (кыргызский = **Kirghiz**). Обязательно.
- **Description** — коротко: кто, язык, подача.
- **Labels:** Accent → Standard; Gender → Male/Female; Age → Young / Middle Aged.
- Upload samples → все почищенные FLAC → дождаться, пока Processing сменится готовностью → Next.

Через API только так же полно: `POST /v1/voices/pvc` с `language` И `labels` (`{"language":"ky", ...}`) сразу при создании.
28.11 клон создали через API без `labels` — проверочную фразу дали на казахском. Клон пришлось удалить и создать заново.

## 4. Верификация (человек)
- Сразу после загрузки, на том же месте, той же петличкой (выбрать её в браузере), той же подачей, что в записи.
- Фраза должна быть на языке клона. Пришла на другом языке — остановиться и проверить настройки шага 3.
- Прочитать один раз и сразу «Стоп». Не прошло — не долбить: подождать 24 ч или написать в support@elevenlabs.io (сбрасывают попытки).

## 5. Обучение и проверка
- После верификации обучение стартует само, 3–6 часов (иногда до суток). Кыргызский учится на моделях v4.
- Готовность: голос в списке Voices без «training». Проба — короткий текст сценария, человек слушает: похож, живой, без акцента.
- На тарифе Creator слот профклона один: новый клон — только после удаления старого.
